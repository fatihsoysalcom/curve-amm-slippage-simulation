# Curve AMM slippage simulation

This Python script simulates a simplified Automated Market Maker (AMM) swap, demonstrating the concept of slippage inherent in decentralized exchanges like Curve. It calculates the expected versus actual output of a trade, illustrating how larger trades or less liquid pools result in greater price impact.

## Language

`python`

## How to Run

Save the code as `curve_amm_sim.py` and run it from your terminal using `python curve_amm_sim.py`.
